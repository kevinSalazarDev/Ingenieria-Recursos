# Cómo contribuir

¡Gracias por ayudar a mejorar esta biblioteca! Las contribuciones deben hacer que los materiales sean más claros, útiles, accesibles y confiables para quienes están aprendiendo programación.

## Antes de proponer cambios

1. Revisa el [README principal](./README.md) y la guía del área correspondiente.
2. Comprueba si el recurso o la corrección ya existe.
3. Conserva los archivos originales cuando no tengas certeza sobre su propósito.
4. Respeta la autoría, las licencias y las condiciones de uso de los materiales de terceros.

## Reportar un error

Abre un issue e incluye:

- Ruta exacta del archivo.
- Qué esperabas que ocurriera.
- Qué ocurre realmente.
- Datos de entrada utilizados, si corresponde.
- Captura o mensaje de error, si ayuda a reproducirlo.

No publiques contraseñas, tokens, datos personales ni otra información privada.

## Proponer un recurso

Incluye, en la medida de lo posible:

- Nombre del recurso y autor o institución.
- Enlace a la fuente original.
- Idioma y nivel aproximado.
- Temas que cubre.
- Requisitos previos.
- Motivo por el que aporta valor a la ruta de aprendizaje.
- Información sobre su acceso y licencia, si está disponible.

Se priorizan recursos gratuitos, legales, accesibles y con una progresión pedagógica clara.

## Enviar cambios mediante Pull Request

1. Crea una rama con un nombre descriptivo.
2. Realiza cambios pequeños y enfocados.
3. Explica qué cambiaste y por qué.
4. Si modificas código Python, prueba el programa y describe los casos comprobados.
5. Comprueba que el verificador de sintaxis de Python pase.
6. Enlaza los issues relacionados, si existen.

## Criterios de calidad

- Usa nombres descriptivos y consistentes.
- Mantén las rutas y enlaces relativos actualizados.
- No elimines ejercicios duplicados sin comparar su contenido y documentar la decisión.
- No presentes como verificado un programa que no se ha ejecutado.
- Evita añadir archivos generados, cachés, credenciales o ejecutables innecesarios.
- Prefiere explicaciones sencillas y ejemplos que ayuden a aprender.

## Autoría y licencias

Este repositorio reúne material propio y material de terceros. La presencia de un archivo aquí no implica que el proyecto sea su autor ni que tenga derechos para relicenciarlo. Consulta la fuente original y conserva sus avisos de autoría y licencia. Si no se conoce la licencia de un material, no asumas que puede redistribuirse libremente.
