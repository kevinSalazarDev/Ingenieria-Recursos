# Fundamentos de Programación

Esta área reúne materiales para aprender lógica, algoritmos y programación desde cero.

## Rutas disponibles

1. [PSeInt y pseudocódigo](./01%20-%20PSeInt%20y%20pseudoc%C3%B3digo/) - primeros pasos en lógica y algoritmos.
2. [Diagramas de flujo con Flowgorithm](./02%20-%20Diagramas%20de%20flujo%20(Flowgorithm)/) - representación visual y ejecución de algoritmos.
3. [Python](./03%20-%20Python/) - fundamentos de un lenguaje de programación.

## ¿En qué orden estudiar?

Si estás comenzando, puedes estudiar primero pseudocódigo, luego diagramas de flujo y finalmente Python. No es obligatorio dominar una herramienta por completo antes de pasar a la siguiente: lo importante es comprender variables, operaciones, decisiones, ciclos y resolución de problemas.

Cada carpeta contiene su propia guía, recursos y ejercicios. Revisa los README antes de comenzar.
