# Programación ATS - Diagramas de flujo

Esta carpeta reúne ejercicios y material de práctica elaborados siguiendo el curso de Programación ATS sobre programación desde cero con diagramas de flujo.

## Curso original

[Ver curso completo en YouTube - Programación ATS](https://www.youtube.com/watch?v=KBC5mhbiy6Y&list=PLWtYZ2ejMVJnpjQFWykrPcVOycJLVP2cG)

## Organización del material

- **01 - Operadores:** ejercicios sobre operaciones y expresiones.
- **02 - Condicionales:** problemas que requieren tomar decisiones.
- **03 - Ciclos y bucles:** ejercicios con estructuras repetitivas.
- **Curso - Programación desde cero con diagramas de flujo:** ejercicios resueltos clasificados por tema.
- **Documentación y archivos DFD:** documentación y archivos relacionados con DFD.

Los nombres y la estructura identifican colecciones de práctica. No se ha cambiado el contenido interno de los ejercicios.

## Recomendación de estudio

1. Comprende el enunciado del problema.
2. Identifica los datos de entrada, el proceso y la salida.
3. Diseña el algoritmo.
4. Ejecuta el diagrama con diferentes valores.
5. Comprueba decisiones y ciclos.
6. Intenta resolver el problema de nuevo sin consultar el archivo.

Los ejercicios pertenecen al material de su fuente original. Consulta el curso para seguir las explicaciones completas.
