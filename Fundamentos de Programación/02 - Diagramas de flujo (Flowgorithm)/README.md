# Diagramas de flujo con Flowgorithm

Esta sección reúne herramientas, cursos y ejercicios para representar algoritmos mediante diagramas de flujo.

Un diagrama de flujo permite visualizar el orden de las instrucciones, las decisiones y los ciclos de un algoritmo. Flowgorithm permite construir y ejecutar estos diagramas, por lo que resulta útil para practicar la lógica antes de trasladarla a un lenguaje de programación.

## 🎯 Objetivos de aprendizaje

- Reconocer los símbolos básicos de un diagrama de flujo.
- Representar entradas, procesos y salidas.
- Construir secuencias de instrucciones.
- Modelar decisiones y condiciones.
- Representar ciclos.
- Probar algoritmos y detectar errores de lógica.

## 🧭 Orden recomendado

1. Conoce los símbolos y el entorno de Flowgorithm.
2. Crea diagramas secuenciales.
3. Practica variables, asignaciones y operaciones.
4. Representa condiciones.
5. Construye ciclos.
6. Resuelve problemas que combinen varios elementos.

Puedes complementar esta sección con los ejercicios de [PSeInt](../01%20-%20PSeInt%20y%20pseudoc%C3%B3digo/) y luego continuar con [Python](../03%20-%20Python/).

## ✅ Cómo practicar

- Dibuja primero la solución en papel si el problema es nuevo.
- Ejecuta el diagrama con varios datos de entrada.
- Comprueba las ramas de las decisiones.
- Verifica que los ciclos terminen cuando corresponde.
- Compara el diagrama con el pseudocódigo y explica las diferencias.

Los cursos y ejercicios de terceros conservan la autoría de sus creadores. Este repositorio los organiza como material de referencia y práctica.
