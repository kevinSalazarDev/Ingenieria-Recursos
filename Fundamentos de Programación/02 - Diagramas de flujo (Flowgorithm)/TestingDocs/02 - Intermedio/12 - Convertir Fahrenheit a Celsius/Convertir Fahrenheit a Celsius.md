# Convertir Fahrenheit a Celsius

**Nivel:** Intermedio · **Herramienta:** Flowgorithm

## Código del diagrama
```xml
<declare name="fahrenheit, celsius" type="Real"/>
<output expression="&quot;Ingrese los grados Fahrenheit:&quot;"/>
<input variable="fahrenheit"/>
<assign variable="celsius" expression="5 * (fahrenheit - 32)/9"/>
<output expression="celsius &amp; &quot; grados Celsius&quot;"/>
```

## Explicación

Solicita una temperatura en Fahrenheit y la convierte a Celsius mediante la fórmula C = 5 × (F − 32) / 9. Después muestra el resultado.
