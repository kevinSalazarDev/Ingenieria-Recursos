# TestingDocs - Flowgorithm

Esta carpeta contiene ejercicios de práctica para trabajar con diagramas de flujo en Flowgorithm.

## Curso original

[Ver lista de reproducción en YouTube - TestingDocs](https://www.youtube.com/playlist?list=PLVHbdCc-UCC1SNtA3HFL36jMbNFPZtzn8)

## Organización

- **01 - Principiante:** ejercicios introductorios de entrada, salida y operaciones básicas.
- **02 - Intermedio:** ejercicios con condicionales y estructuras repetitivas.

Algunos archivos conservan nombres genéricos porque no se ha confirmado su enunciado exacto. Se mantienen para no atribuirles un propósito incorrecto.

## Cómo practicar

Abre los archivos con Flowgorithm, ejecuta los diagramas y prueba distintos valores. Comprueba especialmente las condiciones de salida de los ciclos.

Los ejercicios se conservan como material de práctica asociado a la fuente original.
