# Mostrar varias salidas

**Nivel:** Principiante · **Herramienta:** Flowgorithm

## Código del diagrama
```xml
<output expression="&quot;Salida 1&quot;"/>
<output expression="&quot;Salida 2&quot;"/>
<output expression="&quot;Salida 3&quot;"/>
<output expression="&quot;Salida 4&quot;"/>
```

## Explicación

Ejecuta cuatro instrucciones de salida consecutivas para mostrar los textos «Salida 1» a «Salida 4». Permite observar la secuencia de instrucciones.
