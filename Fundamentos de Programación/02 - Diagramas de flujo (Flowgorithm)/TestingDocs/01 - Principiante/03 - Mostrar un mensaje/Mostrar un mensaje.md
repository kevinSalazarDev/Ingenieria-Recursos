# Mostrar un mensaje

**Nivel:** Principiante · **Herramienta:** Flowgorithm

## Explicación

Muestra en pantalla el texto fijo «EL cielo es azul». Es un ejercicio introductorio para reconocer una instrucción de salida; no requiere declarar variables ni solicitar datos.
