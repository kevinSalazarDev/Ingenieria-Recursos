# Mostrar un mensaje

**Nivel:** Principiante · **Herramienta:** Flowgorithm

## Código del diagrama
```xml
<output expression="&quot;EL cielo es azul&quot;"/>
```

## Explicación

Muestra en pantalla el texto fijo «EL cielo es azul». Es un ejercicio introductorio para reconocer una instrucción de salida; no requiere declarar variables ni solicitar datos.

## Diagrama de flujo

El diagrama editable está en [ejercicio_1.fprg](./ejercicio_1.fprg). Ábrelo con Flowgorithm para visualizarlo y ejecutarlo. Aún no hay una exportación SVG de este ejercicio.
