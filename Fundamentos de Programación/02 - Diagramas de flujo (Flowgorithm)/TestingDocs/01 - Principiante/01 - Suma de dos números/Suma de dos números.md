# Suma de dos números

**Nivel:** Principiante · **Herramienta:** Flowgorithm

## Código del diagrama
```xml
<declare name="num1, num2, resultado" type="Integer"/>
<output expression="&quot;Ingrese dos números: &quot;"/>
<input variable="num1"/>
<input variable="num2"/>
<assign variable="resultado" expression="num1 + num2"/>
<output expression="&quot;El resultado de la suma es: &quot; &amp; resultado"/>
```

## Explicación

Solicita dos números enteros, los suma y muestra el resultado. Practica declaración de variables, entrada, asignación y salida.
