# Leer y mostrar un mensaje

**Nivel:** Principiante · **Herramienta:** Flowgorithm

## Código del diagrama
```xml
<declare name="mensajeDelUsuario" type="String"/>
<output expression="&quot;Ingrese un mensaje:&quot;"/>
<input variable="mensajeDelUsuario"/>
<output expression="&quot;Su mensaje es: &quot; &amp; mensajeDelUsuario"/>
```

## Explicación

Declara una variable de texto, solicita un mensaje al usuario, almacena la entrada y luego la muestra. Practica entrada y salida de cadenas.
