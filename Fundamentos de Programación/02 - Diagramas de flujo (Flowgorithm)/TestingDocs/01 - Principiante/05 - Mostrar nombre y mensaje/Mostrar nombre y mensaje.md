# Mostrar nombre y mensaje

**Nivel:** Principiante · **Herramienta:** Flowgorithm

## Código del diagrama
```xml
<declare name="mensajeDelUsuario, nombreDelUsuario" type="String"/>
<output expression="&quot;Ingrese su nombre: &quot;"/>
<input variable="nombreDelUsuario"/>
<output expression="&quot;Ingrese un mensaje:&quot;"/>
<input variable="mensajeDelUsuario"/>
<output expression="&quot;El usuario &quot; &amp; nombreDelUsuario &amp; &quot; ha escrito &quot; &amp; mensajeDelUsuario"/>
```

## Explicación

Solicita el nombre y un mensaje, guarda ambos textos y genera una frase que relaciona al usuario con el mensaje escrito. El archivo se llama ejercicio_3, aunque el atributo interno conserva el nombre ejercicio_2.

## Diagrama de flujo

El diagrama editable está en [ejercicio_3.fprg](./ejercicio_3.fprg). Ábrelo con Flowgorithm para visualizarlo y ejecutarlo. Aún no hay una exportación SVG de este ejercicio.
