# Área de un rectángulo

**Nivel:** Principiante · **Herramienta:** Flowgorithm

## Código del diagrama
```xml
<declare name="lado, ancho, area" type="Real"/>
<output expression="&quot;Ingrese el lado del rectangulo: &quot;"/>
<input variable="lado"/>
<output expression="&quot;Ingrese el ancho del rectangulo: &quot;"/>
<input variable="ancho"/>
<assign variable="area" expression="lado * ancho"/>
<output expression="&quot;El area del rectangulo es: &quot; &amp; area"/>
```

## Explicación

Pide el lado y el ancho de un rectángulo, calcula el área multiplicando ambas medidas y presenta el resultado. Las variables son de tipo Real para admitir valores decimales.
