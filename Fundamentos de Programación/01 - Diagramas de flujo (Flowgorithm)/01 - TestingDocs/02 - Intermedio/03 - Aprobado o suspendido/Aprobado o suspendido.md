# Aprobado o suspendido

**Nivel:** Intermedio · **Herramienta:** Flowgorithm

## Explicación

Solicita una nota y comprueba si es mayor o igual a 40. Si se cumple la condición muestra «Aprobado»; de lo contrario, muestra «Suspendido».
