# Programación ATS - Curso desde cero con PSeInt

Esta carpeta reúne los apuntes y ejercicios desarrollados siguiendo el curso de Programación ATS.

## Curso original

[Ver el curso completo en YouTube](https://www.youtube.com/watch?v=D38d8SCtYqE&list=PLWtYZ2ejMVJlACGFXj4zpJ8cWdSjF05tm)

## Organización

Cada ejercicio tiene su propia carpeta. Dentro se conserva el archivo original de PSeInt y se incluye un documento Markdown con el objetivo, el código y una explicación.

Los diagramas SVG se muestran en el Markdown cuando existe un diagrama original para ese ejercicio. Los archivos de imagen PNG, si los hay, se conservan como recursos, pero no se enlazan en los apuntes. No se han creado diagramas nuevos ni se ha modificado el código original.

Los ejercicios 22.1 y 22.2 se mantienen separados porque son dos archivos distintos que originalmente compartían numeración y título.
