# Programación ATS - Curso desde cero con PSeInt

Esta carpeta contiene ejercicios y apuntes desarrollados siguiendo el curso de Programación ATS.

## Curso original

[Ver el curso completo en YouTube](https://www.youtube.com/watch?v=D38d8SCtYqE&list=PLWtYZ2ejMVJlACGFXj4zpJ8cWdSjF05tm)

## Organización

Los archivos están identificados por número y tema. Se conservan las lecciones y ejercicios originales; únicamente se normalizaron sus nombres y se añadió la extensión .psc para identificar los archivos de pseudocódigo de PSeInt.

Hay dos archivos que originalmente tenían el mismo número y título de ejercicio secuencial. Se conservaron ambos como 22.1 y 22.2, sin modificar su contenido ni asumir que sean idénticos.

## Uso recomendado

Sigue las lecciones del curso, intenta resolver cada ejercicio antes de revisar el archivo y ejecuta los algoritmos en PSeInt con diferentes entradas.
