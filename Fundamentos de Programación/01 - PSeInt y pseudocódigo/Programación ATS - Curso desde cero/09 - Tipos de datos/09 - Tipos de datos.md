# 09 - Tipos de datos

## Objetivo

Reconocer los tipos de datos básicos que se pueden utilizar al declarar variables en PSeInt.

## Código en PSeInt

```text
Proceso sin_titulo
	Definir numero1 como entero;
	Definir numero2 como real;
	Definir misterio como logica;
	Definir letra Como Caracter;
	Definir palabra como cadena;
	
FinProceso
```

## Explicación

El algoritmo declara cinco variables, cada una con un tipo de dato diferente:

| Variable | Tipo | Uso |
|---|---|---|
| `numero1` | Entero | Almacena números sin parte decimal. |
| `numero2` | Real | Almacena números que pueden tener decimales. |
| `misterio` | Lógico | Almacena valores de verdadero o falso. |
| `letra` | Caracter | Almacena un carácter individual. |
| `palabra` | Cadena | Almacena texto formado por varios caracteres. |

**Importante:** declarar una variable reserva su nombre y establece qué tipo de dato puede almacenar. En este ejercicio todavía no se asignan valores ni se muestran resultados.
