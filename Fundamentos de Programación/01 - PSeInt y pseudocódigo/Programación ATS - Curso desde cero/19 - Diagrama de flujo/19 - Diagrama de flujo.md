# 19 - Diagrama de flujo

## Objetivo

Introduce un algoritmo secuencial: asigna dos valores, solicita un tercero, suma los tres y muestra el resultado.

## Código en PSeInt

```pseint
Proceso programa1
	// Este será nuestro primer programa
	Definir a, b, c, resultado Como Entero;
	a <- 10;
	b <- 5;
	Escribir "Ingrese el valor de c: ";
	Leer c;
	resultado <- a+b+c;
	Escribir "El resultado es: ",resultado;
FinProceso
```

## Explicación

El programa sigue una secuencia de pasos: define los datos necesarios, obtiene los valores de entrada cuando corresponde, realiza el cálculo o evaluación y comunica el resultado. Revisa el orden de las instrucciones y el papel de cada variable para comprender cómo fluye la información.
