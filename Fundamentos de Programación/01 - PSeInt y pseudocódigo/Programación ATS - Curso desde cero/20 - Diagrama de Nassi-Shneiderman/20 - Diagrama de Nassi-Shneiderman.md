# 20 - Diagrama de Nassi-Shneiderman

## Objetivo

Practica una secuencia de instrucciones en la que se asigna un valor, se solicita otro y se calcula su suma.

## Código en PSeInt

```pseint
Proceso programa1
	// Este sera nuestro primer programa
	definir a,b,resultado como enteros;
	a <- 10;
	Escribir "Ingrese el valor de b: ";
	Leer b;
	resultado <- a+b;
	Escribir "El resultado es: ",resultado;
FinProceso
```

## Explicación

El programa sigue una secuencia de pasos: define los datos necesarios, obtiene los valores de entrada cuando corresponde, realiza el cálculo o evaluación y comunica el resultado. Revisa el orden de las instrucciones y el papel de cada variable para comprender cómo fluye la información.
