# 10 - Operaciones de asignación

## Objetivo

Muestra cómo declarar variables de distintos tipos y asignarles valores iniciales.

## Código en PSeInt

```pseint
//Operacion de Asignacion

Proceso principal
	Definir numero1 como entero; //La variable numero1 es entera
	Definir numero2 como real;
	Definir misterio como logica;
	Definir letra como caracter;
	Definir palabra como cadena;
	
	numero1 <- 10;
	numero2 <- 15.7;
	misterio <- Verdadero;
	letra <- "a";
	palabra <- "Hola";
	
	

	
FinProceso
```

## Explicación

El algoritmo declara las variables que necesita, procesa los datos mediante las instrucciones mostradas y presenta el resultado con `Escribir`. Observa especialmente cómo se asignan valores con `<-` y cómo se utilizan las instrucciones de entrada y salida según el ejercicio.
