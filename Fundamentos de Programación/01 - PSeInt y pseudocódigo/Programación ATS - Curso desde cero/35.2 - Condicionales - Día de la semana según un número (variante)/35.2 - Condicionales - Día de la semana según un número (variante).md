# 35.2 - Condicionales - Día de la semana según un número (variante)

## Objetivo

Resuelve el mismo problema del día de la semana utilizando la estructura Segun, una alternativa más directa para seleccionar entre varios valores.

## Código en PSeInt

```pseint
//Elaborar un programa que me muestre los días de las 
//semanas cuando ingrese los siete primeros números.
//(Pseudocódigo)

Proceso ejercicio7
	Definir num Como Entero;
	
	Escribir "Ingrese un número del 1 al 7: ";
	Leer num;
	
	Segun num Hacer
		1: Escribir "Lunes";
		2: Escribir "Martes";
		3: escribir "Miércoles";
		4: Escribir "Jueves";
		5: escribir "Viernes";
		6: escribir "Sábado";
		7: escribir "Domingo";
		De Otro Modo:
			Escribir "Error, el valor es incorrecto";
			
	FinSegun
FinProceso
```

## Explicación

El algoritmo utiliza una estructura de selección o repetición, según corresponda. Sigue la variable de control y revisa cuándo se cumple la condición para entender qué instrucciones se ejecutan y cuántas veces. Comprueba el comportamiento con distintos valores de entrada, incluidos los límites indicados en el ejercicio.
