# PSeInt y pseudocódigo

Esta sección reúne material para aprender los fundamentos de la lógica de programación mediante pseudocódigo y ejercicios con PSeInt.

PSeInt permite escribir algoritmos con una sintaxis cercana al lenguaje natural. Es una herramienta de aprendizaje: ayuda a concentrarse en la lógica antes de pasar a la sintaxis de un lenguaje como Python.

## 🎯 Objetivos de aprendizaje

Al trabajar con estos materiales, busca aprender a:

- Identificar entradas, procesos y salidas.
- Utilizar variables y tipos de datos.
- Aplicar operadores aritméticos, relacionales y lógicos.
- Resolver problemas con estructuras secuenciales.
- Tomar decisiones mediante condicionales.
- Repetir instrucciones mediante ciclos.
- Dividir soluciones en subprocesos o funciones, cuando corresponda.

## 🧭 Orden recomendado

1. Familiarízate con el entorno de PSeInt.
2. Estudia variables, tipos de datos, asignación y entrada/salida.
3. Practica operadores y expresiones.
4. Resuelve ejercicios secuenciales.
5. Continúa con condicionales.
6. Estudia ciclos y estructuras repetitivas.
7. Practica subprocesos y problemas que combinen varios conceptos.

El orden de los archivos puede variar según el curso de origen. Utiliza esta secuencia conceptual como guía y revisa los títulos de los ejercicios.

## ✅ Cómo estudiar

1. Mira la explicación correspondiente.
2. Intenta escribir el algoritmo sin copiarlo.
3. Ejecuta el pseudocódigo en PSeInt.
4. Prueba diferentes entradas, incluidos valores límite.
5. Explica con tus propias palabras qué hace cada instrucción.
6. Si el ejercicio falla, revisa primero la lógica y después la sintaxis.

**Consejo:** no avances únicamente porque el algoritmo ejecuta. Asegúrate de entender por qué funciona y qué ocurre cuando cambian los datos de entrada.
