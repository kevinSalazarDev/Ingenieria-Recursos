# Python

Esta sección reúne cursos, ejemplos y ejercicios para aprender los fundamentos del lenguaje Python.

Python permite trasladar los conceptos de lógica de programación a un lenguaje utilizado en automatización, desarrollo de software, análisis de datos, inteligencia artificial y muchas otras áreas.

## 🎯 Objetivos de aprendizaje

- Instalar y utilizar Python.
- Comprender variables, tipos de datos y expresiones.
- Leer datos y mostrar resultados.
- Utilizar operadores.
- Escribir condicionales y ciclos.
- Crear y utilizar funciones.
- Trabajar con colecciones de datos.
- Comprender los fundamentos de la programación orientada a objetos.

## 🧭 Ruta sugerida

1. Preparar el entorno y ejecutar el primer programa.
2. Variables, tipos de datos y entrada/salida.
3. Operadores y expresiones.
4. Condicionales.
5. Ciclos.
6. Cadenas y colecciones.
7. Funciones y módulos.
8. Archivos y manejo de errores.
9. Programación orientada a objetos.
10. Proyectos pequeños para integrar los conocimientos.

No necesitas estudiar todos los cursos de esta carpeta al mismo tiempo. Escoge un curso principal y utiliza los demás para consultar explicaciones alternativas y practicar.

## 🧪 Método de práctica

- Escribe los ejemplos tú mismo en lugar de limitarte a copiarlos.
- Ejecuta cada programa y cambia los datos de entrada.
- Prueba casos normales, valores límite y entradas inesperadas.
- Resuelve primero el problema sin mirar la solución.
- Cuando termines un tema, crea un programa pequeño que lo utilice.
- Anota los errores que encuentres y cómo los solucionaste.
