# 15 - Operadores - Ejercicio 3 - Intercambiar dos variables

## Código Python

```python
#Hacer un programa para intercambiar el valor de 2 variables

a = int(input("a -> "))
b = int(input("b -> "))

a , b = b , a

print("a:",a)
print("b:",b)
```
