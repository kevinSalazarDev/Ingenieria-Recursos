# Fuentes, autoría y atribuciones

Este repositorio es una biblioteca educativa que organiza ejercicios, apuntes y referencias de distintas fuentes para facilitar el aprendizaje de fundamentos de programación.

## Principio de atribución

- Los cursos, videos, libros, documentación, imágenes, diagramas y ejercicios creados por terceros pertenecen a sus respectivos autores o titulares.
- Los enlaces a cursos y fuentes originales se incluyen en los README de cada colección cuando se conocen.
- La organización, los comentarios y las guías añadidas a este repositorio no convierten al proyecto en autor del material externo.
- No se debe asumir que todos los archivos tienen la misma licencia ni que pueden reutilizarse fuera de los términos de sus autores.
- Si una licencia o procedencia no está clara, consulta al titular antes de redistribuir o reutilizar el material.

## Fuentes identificadas en las guías

- Programación ATS: cursos y ejercicios de PSeInt, Python y diagramas de flujo.
- TestingDocs: ejercicios de Flowgorithm.
- Art0xdev: material de aprendizaje de lógica y diagramas de flujo.
- CS50: ejercicios asociados al material educativo de CS50.
- Tutoriales Programación Ya: ejemplos y ejercicios de programación.
- Curso de Python - ejercicios: ejercicios de práctica organizados en una colección.

Los enlaces originales y las descripciones se encuentran en los README de cada carpeta. La lista puede ampliarse conforme se verifique la procedencia de cada material.

## Solicitar una corrección de atribución

Si eres titular de derechos o conoces la fuente correcta de un archivo, abre un issue con la ruta del material y la referencia correspondiente. Se revisará la atribución, la licencia y, cuando proceda, la permanencia del archivo.
